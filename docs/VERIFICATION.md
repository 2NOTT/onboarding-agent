## 安全与发布边界

CodeRabbit 初审提出 4 项问题，核对后已修正：开发说明的目录/Tool 数量、后端前端错误转义、服务默认绑定回环地址、规则补充 Tool 的 ID 与下游数据依赖。后者先由新增回归检查复现失败，再修复并通过；错误转义也有入口级检查。修复后的范围由本地检查验证，未将初审结果描述成再次外部复审通过。

发布前移除原历史执行日志，清空 Skill 最近测试记录，仅保留空凭据模板。公开包不包含个人简历、面试资料和修改简历用 Prompt。

发布后应从 GitHub 重新克隆，重跑历史扫描，并对在线 HTML 和 Release 文件进行回读核对。公开版本以仓库提交与 Release 为准。

当前 GitHub 登录凭据未授予 workflow 权限，因此未上传可选的 Actions 配置；检查脚本均保留在仓库，GitHub Pages 使用内建静态发布。

本次不证明真实 LLM / Coze 调用质量、完整身份认证、企业权限、生产并发、全浏览器兼容或完整无障碍合规。远端 Coze 节点定义不在仓库中，导出的 JSON 不是 Coze 原生导入文件。
